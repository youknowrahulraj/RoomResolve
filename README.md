# RoomResolve 🏠
**Student Hostel Complaint Management System**

A hackathon-ready MVP web application that lets students submit and
track hostel complaints while giving administrators a full management
dashboard.

---

## Features
- Student registration & login
- Submit complaints with image attachments
- Real-time status tracking (Pending → In Progress → Resolved)
- Admin dashboard with statistics
- Admin can update and delete complaints

---

## Tech Stack
| Layer       | Technology                     |
|-------------|-------------------------------|
| Frontend    | HTML5, CSS3, Bootstrap 5      |
| Backend     | Python Flask                  |
| Database    | SQLite + Flask-SQLAlchemy     |
| Auth        | Flask Sessions + Werkzeug     |
| Forms       | Flask-WTF + WTForms           |
